# 体验官关键页面清单

## 主页/练习页（核心）

### 顶部区域
- Logo + 标题
- 分数显示
- XP 进度条（当前等级 + 经验值进度）
- 连击计数（连续答对次数）
- 奖杯按钮（每日挑战）
- 奖牌按钮（成就徽章）
- 数据库按钮（数据管理）

### 中部区域
- 词典选择下拉框
- 模式切换 ToggleGroup（填空模式/听写模式/选择题模式/连词成句）

### 练习区域
- 题目卡片
- 中文翻译提示
- 输入框（填空/听写模式）
- 选项卡片（选择题模式）
- 单词池（连词成句模式）
- 音频播放按钮
- 速度调节（0.5x ~ 1.5x）

### 底部区域
- 提示文案（模式相关）
- 移动端底部导航栏

## 答题反馈

### 正确反馈
- 绿色正确提示
- XP 弹窗动画（显示获得 XP + 连击倍数）
- 连击计数更新

### 错误反馈
- 红色"你的答案"区域
- 绿色"正确答案"区域
- 蓝色"解析"区域
- 下一题按钮

## 专注模式（全屏无干扰）

- 顶部：进度（X/Y）+ 分数 + XP + 退出按钮
- 内容：题目卡片放大显示
- 无顶部导航栏、无底部提示、无移动端导航

## 每日挑战面板

- 奖杯图标 + 日期
- 任务卡片列表
- 进度条（X/Y 格式）
- "领取"按钮（完成后可点击）
- 已完成状态（灰色徽章）
- 空状态（全部完成时显示礼物图标）

## 成就徽章面板

- 顶部：已解锁数量徽章
- 分类展示（答题/连击/等级/任务/特殊）
- 已解锁卡片：金色边框 + 解锁日期
- 未解锁卡片：灰色边框 + 进度条 + 距离

## 学习排行榜

- 分类切换：总分榜 / 准确率榜 / 速通榜
- 时间筛选：今日 / 本周 / 全部
- 前三名：奖牌样式（黄/银/铜）
- 排名列表：排名 + 词典名 + 分数 + 正确率/速度 + 时间

## 错题本

- 错题列表
- 每条：题目 + 你的错误答案 + 正确答案
- 删除按钮
- 标记已复习
- 专项复习入口

## 智能复习

- 待复习数量徽章
- 按词典分组显示
- "开始复习"按钮
- 空状态

## 学习历史

- 按日期分组（今天/昨天/更早）
- 记录卡片：词典 + 分数 + 正确率 + 用时 + 题数
- 清除全部按钮

## 移动端特有

- 底部固定导航栏（5个图标）
- 词典切换在主内容区顶部
- 输入框宽度自适应

## 桌面端特有

- 顶部导航按钮组
- 更大的输入框和按钮
- 间距更宽松

## 响应式断点

- 移动端：< 768px（底部导航显示）
- 桌面端：≥ 768px（顶部导航显示）

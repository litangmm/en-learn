# En-Learn 产品说明

## 产品定位

En-Learn 是一款英语学习工具，核心是"听写+选择"练习模式，帮助用户通过单词填空、句子练习提升英语能力。

## 目标用户

- 英语学习者（初中级）
- 希望利用碎片时间学习
- 需要即时反馈和进步感

## 核心功能

### 练习模式

1. **填空模式** - 看中文提示，在输入框中填写单词
2. **听写模式** - 听音频，根据中文提示和首字母提示填写单词
3. **选择题模式** - 四选一快速练习，从四个选项中选择正确答案
4. **连词成句** - 将打乱的单词点击排列成完整句子

### 游戏化激励

1. **XP 积分与等级** - 完成练习获得积分，积累升级
2. **连击系统** - 连续答对获得连击，XP 加成翻倍（2连1.5x，5连2x，10连3x）
3. **每日挑战** - 每日任务获取奖励 XP
4. **成就徽章** - 达成里程碑解锁徽章（答题/连击/等级/任务等）
5. **学习排行榜** - 本地排名展示（总分/准确率/速通）

### 学习辅助

1. **错题本** - 记录错题，可专项复习
2. **智能复习** - 间隔重复算法安排复习
3. **学习历史** - 查看历史练习记录
4. **数据导入导出** - 本地备份/恢复

## 使用流程

1. 选择词典（CET4/CET6/考研/托福等）
2. 选择练习模式（填空/听写/选择/连词成句）
3. 开始练习（答完按回车或点击确认）
4. 查看结果反馈（正确绿色提示，错误显示正确答案和解析）
5. 点击"下一题"或按 Enter 继续
6. 完成一组后查看成绩（得分、正确率、用时）
7. 可选：进入错题本复习、查看排行榜、领取每日奖励

## 关键交互

- **填空输入**：在输入框中输入单词，按 Enter 提交
- **音频播放**：点击播放按钮听音频
- **模式切换**：点击 ToggleGroup 切换模式
- **连击动画**：连续答对后出现 XP 弹窗和连击计数动画
- **专注模式**：点击"专注模式"进入全屏无干扰界面，按 ESC 退出
- **词典切换**：下拉选择不同词典，切换会清空当前进度

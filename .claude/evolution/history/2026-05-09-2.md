## 1. 本次 Epic / Iteration 实现摘要

**Epic**: 最小可行学习数据系统 (epic-001)

本次循环完成了 Epic-001 的 iter-002 和 iter-003 两个迭代。

### Iter-002 — 错题本 MVP

扩展存储服务到 V2，实现错题捕获与专项练习能力：

- 新增 `Mistake` 类型：`sentenceId`, `sentence`, `wrongAnswer`, `correctAnswer`, `dictionaryId`, `timestamp`, `reviewedCount`
- 存储服务扩展：新增 `en-learn-mistakes` key，实现 `addMistake` / `getMistakes` / `removeMistake` / `clearMistakes` / `getMistakeCount` / `incrementReviewedCount`
- 错题去重：按 `sentenceId` 去重，避免重复记录同一错题
- V1 向后兼容：`loadSession` 时自动从 V1 session 中提取 pendingMistakes 并迁移到 V2 mistakes key
- `usePractice` hook 集成：捕获答错的句子到 `pendingMistakes` 状态，会话完成时批量持久化到 storage
- 支持错题练习模式：`sentenceIds` 参数传入时仅练习指定句子
- `MistakeBook` 组件：展示错题列表（含句子原文、错误/正确答案标记）、删除错题、标记复习次数、从错题开始练习
- `App.tsx` 集成：顶部导航增加「错题本」按钮（带数量角标），支持练习/错题本视图切换，错题练习流

### Iter-003 — 学习历史记录

在存储服务上叠加学习历史能力，实现进度可视化：

- 新增 `SessionHistory` 类型：`id`, `timestamp`, `duration`, `dictionaryId`, `dictionaryName`, `score`, `totalQuestions`, `correctCount`, `accuracy`
- 存储服务扩展：新增 `en-learn-history` key，实现 `addHistory` / `getHistory` / `clearHistory` / `getHistoryCount`
- 100 条上限自动截断：超限自动移除最旧记录
- `isValidHistory` 校验函数：过滤非法数据（非对象、缺失必需字段、类型错误）
- 损坏 JSON 降级恢复：清除损坏数据，保留其他 key
- `usePractice` hook 集成：`sessionStartTimeRef` 追踪全新会话起始时间；`isComplete=true` 时自动计算 duration，调用 `storage.addHistory` 记录本次会话
- `HistoryView` 组件：按日期分组（今天/昨天/更早）展示记录卡片，显示词典名、得分、正确率、时长、题目数；支持一键清空（带确认对话框）；空状态友好提示
- `App.tsx` 集成：扩展 `View` 类型，顶部导航增加「学习记录」按钮（带数量角标），三视图切换（练习/错题本/学习记录）

## 1. 本次迭代实现摘要

iter-004 为 en-learn 应用增加了完整的数据导入导出能力，使用户可以安全备份和迁移学习数据。

### 核心实现

- **ExportData 类型**：定义在 `src/services/storage.ts` 中（避免循环依赖），包含 `version: 1`、`exportedAt` ISO 时间戳、`data` 对象（session/mistakes/history）。
- **exportAllData()**：聚合 localStorage 中全部 3 个 key 的数据为 JSON 对象返回。
- **importAllData(data: unknown)**：递归校验 ExportData schema，验证 version、exportedAt、data 结构及各子项（session/null 或 V2、mistakes/isValidMistake、history/isValidHistory），校验通过后写入对应 localStorage key，返回结构化结果（success + importedCounts + message）。
- **DataManager 组件**：
  - 数据概览卡片（学习记录条数、错题数量、是否有未完成会话）
  - 「导出数据」按钮：触发浏览器下载 JSON 文件（`en-learn-backup-YYYY-MM-DD.json`）
  - 「导入数据」按钮：隐藏 `<input type=file accept=.json>` 选择文件，读取后调用 `storage.importAllData`
  - 导入前确认对话框（提示覆盖现有数据）
  - 成功/失败 inline alert 状态显示
- **App.tsx 扩展**：新增 `'data'` 视图类型，顶部导航添加 Database 图标按钮，视图切换逻辑完善。

### 技术亮点

- 递归校验策略（isValidExportData → isValidMistake/isValidHistory）确保任何非法数据都无法进入 localStorage
- 纯前端实现，零外部依赖，blob 下载兼容现代浏览器
- App.tsx 4 视图切换（practice/mistake-book/history/data）仍保持清晰的导航结构

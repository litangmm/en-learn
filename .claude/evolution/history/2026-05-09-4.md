## 1. 本次迭代实现摘要

bugfix-001 是一次高优先级用户体验 Bug 修复迭代，响应用户直接反馈的 3 个核心痛点。本次修复通过指令系统（directive-urgent-001）临时插入 Epic 流程，修复完成后 Epic 继续推进。

### Bug 1 — 重置后题目顺序不变

**问题**：点击「重置」按钮后，题目顺序与之前完全相同，用户感觉「还是同一组题」。

**根因**：`usePractice.ts` 中的 `shuffledSentences` 使用 `useMemo` 计算，依赖数组仅包含 `sentences` 和 `sentenceIds`，而 `reset()` 虽然重置了状态但没有触发 `useMemo` 重新计算。

**修复**：
- 新增 `shuffleSeed` state（初始值 0）
- 将 `shuffleSeed` 纳入 `shuffledSentences` 的 `useMemo` 依赖数组
- `reset()` 中通过 `setShuffleSeed(prev => prev + 1)` 递增 seed，强制 `useMemo` 重新计算随机排序

### Bug 2 — 答对后需手动点击「下一题」

**问题**：用户回答正确后，必须移动鼠标点击「下一题」按钮才能继续，打断键盘输入流。

**修复**：
- 在 `App.tsx` 中添加全局 `window` keydown 监听
- 使用 `useRef` 保存 `state`、`view`、`dialog` 状态和 `nextSentence` 函数的最新引用，避免 stale closure 和频繁重新注册事件监听器
- 当按下 Enter 或 Space 时，如果当前处于 practice 视图、无弹窗、且 `showResult && isCorrect && !isComplete`，则调用 `e.preventDefault()` 并触发 `nextSentence()`
- 当焦点在 INPUT/TEXTAREA 元素上时不处理，避免干扰表单输入

### Bug 3 — 题目标签泄露答案

**问题**：PracticeCard 的 Badge 显示 `第 {sentence.id} 题`，例如「第 CET4-African 题」，直接暴露了英文单词。

**修复**：
- `PracticeCard.tsx` props 接口新增可选的 `currentQuestion?: number` 和 `totalQuestions?: number`
- Badge 内容改为：当 props 存在时显示 `第 X/Y 题`，否则回退到 `第 {sentence.id} 题`（保持向后兼容）
- `App.tsx` 在调用 `PracticeCard` 时传入 `currentQuestion={currentQuestion}` 和 `totalQuestions={totalQuestions}`

### 测试稳定性修复

`App.keyboard.test.tsx` 在单独运行时通过、全量运行时失败。根因为缺少 `cleanup()` 导致 DOM 污染和 mock 状态泄漏。修复措施：
- `afterEach` 中添加 `cleanup()`（从 `@testing-library/react` 导入）
- `vi.clearAllMocks()` 改为 `vi.restoreAllMocks()` 确保 Math.random mock 正确恢复
- `beforeEach` 中 `vi.spyOn(Math, 'random').mockReturnValue(0.5)` 保证确定性 shuffle 顺序
- storage 模块从 `vi.mock()` 改为 `vi.spyOn(storage, 'method')` 避免模块级 mock 冲突

## 5. 关键设计决策

### 索引结构
- `byId`: Map<string, IndexEntry> — O(1) 按 ID 查询
- `byWord`: Map<string, string[]> — O(1) 按单词查询（lowercase）
- `byLevel`: Map<string, string[]> — O(1) 按难度等级查询

### 惰性初始化
- 索引在首次调用 loadDictionary 时构建
- 已构建的词典跳过重复构建
- 多词典并行索引，互不干扰

### 测试策略
- Hook 测试覆盖所有公开 API
- 工具函数测试覆盖边界情况（空数据/单条/多条/特殊字符）
- 全量回归确保零回归

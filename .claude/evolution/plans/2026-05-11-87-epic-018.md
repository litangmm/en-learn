# epic-018 iter-002：能力雷达图与进度趋势

## Overview
- **Epic**: epic-018 学习路径追踪与成就系统整合
- **Iteration**: iter-002
- **Scope**: frontend-only
- **Status**: in_progress
- **Goal**: 新增 AbilityRadar 组件（SVG 雷达图展示 4 种模式能力）、ProgressTrend 组件（最近 7 天学习趋势折线图），集成到 ProgressHub。

## Implementation Steps

### Step 1: 扩展 useProgressStats Hook
**文件**: `src/hooks/useProgressStats.ts`

新增两个函数：
- `getModeAccuracy()`: 计算 fill-in-blanks/multiple-choice/sentence-reorder/dictation 四种模式的正确率和答题数
- `getDailyXP(days: number)`: 计算最近 N 天每日 XP 变化，返回 `{ date: string, xp: number, questions: number }[]`

**关键设计**:
- SessionHistory 中无 mode 字段，需从历史数据反推或从 practiceState 中提取
- 考虑增加 storage.getModeStats() 从 badgeProgress 扩展
- 雷达图 4 轴：填空(fill-in-blanks)、选择(multiple-choice)、排序(sentence-reorder)、听写(dictation)

### Step 2: 创建 AbilityRadar 组件
**文件**: `src/components/AbilityRadar.tsx`

- SVG 五边形雷达图，4 个轴（上下左右或斜角）
- 每个轴表示一种模式的正确率（0-100%）
- 填充区域用半透明颜色
- 支持 mobile (200px) / desktop (280px) 响应式尺寸
- 无数据时显示「暂无数据」占位

**数据结构**:
```typescript
interface ModeAccuracy {
  mode: 'fill-in-blanks' | 'multiple-choice' | 'sentence-reorder' | 'dictation';
  accuracy: number;
  totalQuestions: number;
}
```

### Step 3: 创建 ProgressTrend 组件
**文件**: `src/components/ProgressTrend.tsx`

- SVG 折线图，展示最近 7 天每日学习趋势
- 支持两种指标切换：答题数 / XP
- 触摸交互显示每日详情 tooltip
- 无数据时显示「坚持学习解锁趋势图」占位
- X 轴：日期（周几），Y 轴：数值

**数据结构**:
```typescript
interface DailyTrend {
  date: string; // 'YYYY-MM-DD'
  dayName: string; // '周一' 等
  xp: number;
  questions: number;
  accuracy: number;
}
```

### Step 4: 更新 ProgressHub
**文件**: `src/components/ProgressHub.tsx`

在里程碑网格下方添加：
- 「能力雷达」可点击卡片区域（包含 AbilityRadar 组件）
- 「学习趋势」可点击卡片区域（包含 ProgressTrend 组件）
- 两个卡片并排显示（mobile 单列堆叠）

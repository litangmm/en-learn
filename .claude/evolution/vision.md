# en-learn 产品愿景

## 核心目标
打造最智能的英语词汇学习工具，让每个人都能高效记忆单词、提升听力。

## 用户价值主张
1. **多模态学习**：听、说、读、写结合，不单调
2. **智能记忆**：基于遗忘曲线的个性化复习
3. **数据驱动**：学习进度可视化，让进步看得见
4. **极致轻量**：打开即用，无需注册，零门槛

## 当前阶段重点
- 核心练习模式从单一听写扩展到多样化
- 学习数据持久化（localStorage）
- 复习机制（错题本 + 智能推送）
- 学习进度统计

## 技术原则
- 纯前端，零后端依赖
- 构建产物小，加载快
- 测试覆盖核心用户流程
- 代码整洁，技术债务及时清理

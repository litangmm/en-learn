# 需求规格：用户完整体验评测反馈

> 提出者：用户（真实学习者完整体验）
> 日期：2026-05-09
> 关联指令：`dir-user-review-001`

---

## 1. 概述

用户从学习者角度完整体验了 en-learn 全站功能后，提交了系统性评测报告。报告指出产品在**移动端适配**和**学习逻辑一致性**两方面存在显著问题，阻碍其从"功能丰富的 demo"升级为"可靠的日常学习工具"。

本规格将评测反馈转化为可执行的工程需求，按 P0/P1/P2/P3 四级优先级组织。

---

## 2. 好用的地方（保留）

1. 核心练习路径清楚：进入后直接开始，题卡/进度/音频/提交在主区域
2. 答题反馈及时：答对后显示鼓励语+分数+XP，有轻量游戏化效果
3. 错题体系完整：原句/中文/你的答案/正确答案/尝试次数/时间，可标记已复习或删除
4. 长期学习功能有雏形：学习记录/每日挑战/智能复习/数据管理/导入导出
5. 词库覆盖面不错：初中/高中/CET-4/CET-6/雅思/托福/GRE
6. 专注模式方向正确：隐藏大部分导航，保留题目/进度/得分/退出

---

## 3. 不好用 / 有问题的地方（需修复）

### P0 — 移动端基础可用性（必须先修）

#### 问题 1：移动端横向溢出
- **现象**：390px 宽度下，题卡内容被横向裁切，右侧音频按钮和英文句子超出屏幕，底部提示文字被截断
- **根因**：
  - `PracticeCard` 句子区域 `text-center` 但没有换行保护
  - 输入框固定 `w-28 md:w-32`，多个输入框+英文文本组合后总宽超出视口
  - 顶部模式切换 `ToggleGroup` 4 个按钮横向排列，在小屏下被压缩
- **修复要求**：
  - 句子+输入框区域在移动端允许横向滚动或弹性换行
  - 输入框在移动端改为 `min-w-[80px] flex-1` 或换行布局
  - 模式切换在移动端改为 2x2 网格 (`grid-cols-2`) 或支持横向滚动
  - 核心答题区域必须保证不被裁切

#### 问题 2：桌面端顶部标题挤压
- **现象**：当前浏览器宽度下，左上角「听力词汇练习 / 听句子，填单词」被压成竖排
- **根因**：Header 中间区域（XPBar + StreakFeedback + Trophy + Award + 得分）不折叠，挤占标题空间
- **修复要求**：
  - 中间区域增加 `flex-wrap`
  - 窄屏时标题文字缩小或简化为仅 logo + "en-learn"
  -  Trophy/Award 图标在较窄桌面宽度下可隐藏文字仅显示图标

#### 问题 3：顶部导航项目过多
- **现象**：桌面端导航项目（错题本/学习记录/数据管理/智能复习/每日挑战/成就）在中等宽度下挤压内容区
- **修复要求**：
  - 桌面端保留完整导航
  - 窄桌面或中等宽度下，将次要导航收进「更多」下拉菜单或底部导航
  - 保证标题区域有足够弹性空间

### P1 — 学习逻辑一致性与反馈清晰度

#### 问题 4：模式提示文案不随模式变化
- **现象**：选择题和连词成句模式下，底部仍显示「听音频后，在输入框中填入缺失的单词，按 Enter 键快速提交」
- **修复要求**：根据 `practiceMode` 动态渲染：
  - `fill-in-blanks`：听音频后，在输入框中填入缺失的单词，按 Enter 键快速提交
  - `dictation`：听音频后，根据中文提示和首字母提示填写单词
  - `multiple-choice`：选择最合适的答案后，点击提交答案按钮
  - `sentence-reorder`：点击单词组成正确句子，再次点击已选单词可撤回

#### 问题 5：答错后正确答案展示混淆
- **现象**：用户输入 `walk` 后旁边出现 `attempt`，视觉上像同一句里的额外文本
- **修复要求**：
  - 改为独立反馈卡片，分区展示：
    - 「你的答案」区域（红色背景）
    - 「正确答案」区域（绿色背景）
    - 「解析」区域（可选，显示词义说明）
  - 不再把正确答案小字插在输入框下方

#### 问题 6：选择题选中态不够明显
- **现象**：点击选项后，用户不容易确认自己选中了哪个
- **修复要求**：
  - 选中态增加 `CheckCircle2` 勾选图标（放在选项卡片右上角或左侧）
  - 选中态背景色差异更强（如 `bg-blue-100` → `bg-blue-200`）
  - 或增加「已选中」文字标签

#### 问题 7：连词成句提交按钮置灰但原因不明确
- **现象**：未选择词时按钮灰色，用户可能以为按钮坏了
- **修复要求**：
  - 按钮置灰时增加 Tooltip：「请先点击下方单词组成完整句子」
  - 或在按钮下方显示提示文字
  - 或在答案区上方增加进度提示：「已选 3/8 个单词」

### P2 — 模式语义与数据质量

#### 问题 8：模式语义混乱
- **现象**：
  - 填空模式第一题是句子填词，后面出现释义类内容（如 `make an effort or ___; "He tried..."`）
  - 选择题选项混有完整句子和释义
  - 连词成句排列的是释义句，而非原英文例句
- **根因**：数据中的 `english` 字段混用了「完整例句」和「词典释义」两种格式
- **修复要求**（短期方案）：
  - `multiple-choice` 选项渲染时，若 `english` 长度超过阈值或包含引号/分号等释义特征，优先显示 `chinese` 作为题干，选项统一为单词/释义
  - `sentence-reorder` 过滤掉不含完整句子的题目（可通过正则判断首字母大写+结尾句号）
  - 或给 `Sentence` 类型增加 `isExampleSentence: boolean` 标记，在生成题目时过滤

### P3 — 智能复习可信度

#### 问题 9：智能复习缺乏规则说明
- **现象**：入口叫「智能复习」，页面显示「7题到期」「从未复习」，但没有解释复习规则
- **修复要求**：
  - 页面顶部增加规则说明横幅：
    - 「复习间隔：第1次错误后1天 → 3天 → 7天 → 14天」
    - 「排序规则：按最近错误时间和复习次数综合排序」
  - 给每题增加优先级标签：
    - 红色「高优先级」：错误次数 >= 2 或从未复习
    - 蓝色「今日到期」：nextReviewAt <= now
    - 绿色「已掌握」：reviewedCount >= 3 且连续答对

## 5. 验收标准

- [ ] 在 iPhone SE (375px) 和 iPhone 14 (390px) 模拟器下，题卡内容无横向溢出
- [ ] 在 1280px 桌面宽度下，Header 标题不被挤压成竖排
- [ ] 切换四种练习模式时，底部提示文案正确对应当前模式
- [ ] 答错后，你的答案和正确答案分开展示，视觉不混淆
- [ ] 选择题点击选项后，有明确的勾选图标或「已选中」标识
- [ ] 连词成句未选完时，用户能明确知道为什么提交按钮不可用
- [ ] 智能复习页面能向用户解释复习排序规则和间隔算法
